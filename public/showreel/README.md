# Optional owned showreel video

Add your own licensed/owned `wixnova-reel.mp4` (muted, 8–15 seconds, 16:9, compressed MP4) here.
The hero automatically uses it when the browser can play it, falling back to a polished animated presentation of EXISTING `lib/data.json` client outcomes otherwise.
Do not add stock footage or claim the fallback is a real client-site video.
Recommended export: 1920x1080 H.264, no audio track, optimized for web, under ~5 MB.
